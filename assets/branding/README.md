# StudioSP logo

`StudioSPLogo.png`: transparent horizontal wordmark, four sampler pads with a waveform cutout, white STUDIO and lime SP. Generated with the built-in ImageGen tool, followed by a refinement edit. Embedded in the Standalone/VST3 binaries via JUCE BinaryData; no external image file is required after installation. The UI fits the visible alpha bounds once at editor creation and scales the artwork with the rest of the interface.

## Generation prompt

Create ONE polished, original horizontal logo asset for a music sampler VST instrument named STUDIO SP. Transparent PNG background, actual transparent alpha, no dark rectangle, no mockup or presentation scene. One single centered horizontal logo lockup, approximately 6:1 content aspect ratio, use a wide landscape canvas with transparent margins. On the left a distinctive minimal acid-lime (#BCF468) geometric emblem: four squared sampler pads forming a compact 2x2 grid, with the negative space suggesting a crisp lightning-like audio pulse / waveform. Make it recognizable at 32 px, bold simple forms, no tiny details, no circles. On the right exact clearly readable text 'STUDIO SP' in strong custom-looking condensed geometric uppercase typography, slightly forward, professional electronic-music hardware aesthetic. STUDIO in near-white (#F4F7EF), SP in acid-lime (#BCF468). Balanced close spacing, emblem and letters aligned to same optical height. Flat vector-like edges and solid colors only; no gradients, shadows, glow, chrome, textures, slogans, extra letters, extra symbols, watermarks or duplicate logos. Overall character: precise, tactile, restrained, premium sampler instrument. Asset will be drawn on a charcoal #111416 app header, so white/lime must remain high contrast. Fill canvas width with the logo, leave only sensible transparent padding. This is the final production logo, not a concept sheet.

## Refinement prompt

Refine this exact Studio SP logo into a clean final production asset. Preserve the same four-pad waveform emblem, the same wordmark letter shapes, arrangement, spacing and white/lime color separation. Remove ALL distressed texture, scratches, flecks, noise, stray pixels, rough edges and gradients. Letter interiors must be completely solid near-white #F4F7EF for STUDIO and completely solid lime #BCF468 for SP. Emblem completely solid lime #BCF468. Edges smooth, crisp, vector-like. No other changes. Keep text exactly STUDIO SP and keep the genuine transparent background. Tight horizontal logo lockup with modest transparent padding; no background, no mockup, no added text.
